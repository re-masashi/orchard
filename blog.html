Awesome Gamedev Resources

Cool resources I found. Mostly C++ specific.

Der Name ist Programm. I might forget these later so I thought I’d just list them here.

AMD FidelityFX

I thought this might be slop but, it looks pretty promising. Here’s the link. FSR works across platforms (upto FSR 3 afaict). It also offers adaptive sharpening, some screen space reflection and ambient occlusion stuff and a denoiser. There's also a fork that works on Linux.

Jolt

Jolt is a performant physics engine with an easy to use (imo) API. It’s been used by Horizon Forbidden West and Death Stranding 2 and it’s been Godot’s default physics engine for a while now. This document shows how Jolt performs compared to other physics engines.

STB (specifically, stb_image)

stb has a bunch of different singly file libraries ranging from lexers to perlin noise generators to image loading to leak checking and what not. It’s pretty cool.
